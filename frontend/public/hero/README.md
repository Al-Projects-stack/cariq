# Hero + social images - drop yours here

| File      | Used for                              | Size        |
|-----------|---------------------------------------|-------------|
| `hero.jpg` | Landing hero photo below the CTA     | 1600x900px  |
| `og.jpg`   | Social share card (`og:image` meta)  | 1200x630px  |

`.jpeg` / `.webp` / `.png` variants of `hero` also work - the UI tries
`hero.jpg` -> `hero.jpeg` -> `hero.webp` -> `hero.png` in order.

Both are optional: the pages render cleanly without them, and light up
automatically once the files exist. No code changes needed.
