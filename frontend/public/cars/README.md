# Car photos - drop yours here

One file per model. `.jpg` preferred (small + fast). `.jpeg` / `.webp` / `.png` also work -
the UI tries them in that order automatically.

## Filenames (exact, lowercase)

```
bmw_3_series.jpg              <- BMW 3 Series
chery_tiggo_4_pro.jpg         <- Chery Tiggo 4 Pro
ford_ranger.jpg               <- Ford Ranger
haval_jolion.jpg              <- Haval Jolion
honda_jazz.jpg                <- Honda Jazz
hyundai_grand_i10.jpg         <- Hyundai Grand i10
hyundai_i20.jpg               <- Hyundai i20
hyundai_ix35.jpg              <- Hyundai ix35
isuzu_d_max.jpg               <- Isuzu D-Max
kia_sportage.jpg              <- Kia Sportage
mazda_3.jpg                   <- Mazda 3
mercedes_benz_c_class.jpg     <- Mercedes-Benz C-Class
nissan_np200.jpg              <- Nissan NP200
suzuki_swift.jpg              <- Suzuki Swift
toyota_corolla_cross.jpg      <- Toyota Corolla Cross
toyota_fortuner.jpg           <- Toyota Fortuner
toyota_hilux.jpg              <- Toyota Hilux
volkswagen_golf.jpg           <- Volkswagen Golf
volkswagen_polo.jpg           <- Volkswagen Polo
volkswagen_polo_vivo.jpg      <- Volkswagen Polo Vivo
```

Rule: lowercase `make_model`, anything that isn't `a-z0-9` becomes `_`.
So `Mercedes-Benz / C-Class` -> `mercedes_benz_c_class`.

## Size guide

- **Cards / profiles / compare:** 800x450px (16:9), ~80-150KB, quality 70-80.
- Keep `_placeholder.svg` - it shows until you add real photos.

That's it. No code changes needed - just drop files and rebuild.
